# IT Learning Portal

社内IT・ITサポート・インフラ運用をこれから担当する人のための、VitePress製の社内学習ポータルです。

## Demo v3

v3では、v2のコンテンツ構成を保ちながら、次の点を改善しています。

- ホーム画面の情報設計と視認性
- 学習の入口とおすすめルート
- カード、見出し、ボタンの統一
- スマートフォン表示
- ダークモード表示
- 新しいホーム用SVG

## ローカル起動

```bash
npm install
npm run docs:dev
```

## ビルド確認

```bash
npm run docs:build
```

## GitHub Pagesへの反映

```bash
git add .
git commit -m "Update portal demo v3"
git push
```
