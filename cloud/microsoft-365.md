# Microsoft 365
<div class="lesson-meta"><span>クラウド</span><span>初級</span><span>約15分</span></div>
<div class="lesson-lead">Microsoft 365は、メール、共同作業、ファイル共有、認証、端末管理などを提供するクラウドサービス群です。社内IT担当者は「Officeを使うための契約」だけではなく、利用者とサービスを管理する基盤として理解します。</div>

## 主なサービス
| サービス | 主な役割 |
|---|---|
| Exchange Online | メールと予定表 |
| Teams | チャット、会議、共同作業 |
| SharePoint Online | 組織・チームの情報共有 |
| OneDrive | 個人用の業務ファイル保管 |
| Microsoft Entra ID | クラウド上のIDと認証 |
| Microsoft Intune | 端末とアプリの管理 |

## 入社対応での流れ
<div class="scenario-flow"><span>ユーザー作成</span><b>→</b><span>ライセンス割り当て</span><b>→</b><span>グループ・権限設定</span><b>→</b><span>端末準備</span><b>→</b><span>利用確認</span></div>

::: warning ライセンスだけで判断しない
利用できない原因は、ライセンス不足だけとは限りません。サインイン状態、サービス障害、グループ、条件付きアクセス、端末状態などを順に確認します。
:::
