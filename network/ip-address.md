# IPアドレス
<div class="lesson-meta"><span>ネットワーク</span><span>初級</span><span>約15分</span></div>
<div class="lesson-lead">IPアドレスは、ネットワーク上の機器を識別するための住所です。新人のうちは計算よりも、設定画面を見て「何が正常で、何が怪しいか」を判断できることを目標にします。</div>

## まず確認する四つの値
| 項目 | 役割 |
|---|---|
| IPアドレス | その端末自身の住所 |
| サブネットマスク | 同じネットワークの範囲を判断する情報 |
| デフォルトゲートウェイ | 別のネットワークへ出るための出口 |
| DNSサーバー | 名前解決を依頼する相手 |

## Windowsでの確認
```powershell
ipconfig /all
```

::: warning 169.254.x.x が表示された場合
DHCPから正常にIPアドレスを取得できず、Windowsが自動的に仮のアドレスを設定している可能性があります。LANケーブル、無線接続、DHCPサーバー、VLANなどを確認します。
:::

## 問い合わせ対応の順序
1. 接続状態を確認する
2. `ipconfig /all` で値を確認する
3. 同じ場所の正常な端末と比較する
4. ゲートウェイへ通信できるか確認する
5. DNSの名前解決を確認する
