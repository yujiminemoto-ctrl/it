# このポータルについて
<div class="lesson-meta"><span>はじめに</span><span>約5分</span></div>

<div class="lesson-lead">このサイトは、ITの知識を広く集めた百科事典ではありません。社内IT担当者が、日々の問い合わせや運用作業で必要になる基本を、仕事の流れに沿って確認するための知識庫です。</div>

## 想定している読者
- IT未経験で社内IT部門へ配属された人
- ヘルプデスクやITサポートを担当する人
- 将来、Windows、ネットワーク、Microsoft 365、端末管理を担当する人

## 読み方
最初からすべて暗記する必要はありません。まず「何のための仕組みか」を理解し、実際の問い合わせに出会ったときに戻ってきてください。

::: tip 新人のうちは、分からないことが正常です
大切なのは、分からないまま操作を続けることではなく、状況を整理し、確認し、必要なら先輩へ正しく相談できることです。
:::
