# Active Directory
<div class="lesson-meta"><span>Windows</span><span>認証基盤</span><span>初級</span><span>約25分</span></div>
<div class="lesson-lead">Active Directory Domain Servicesは、会社のユーザー、PC、サーバーをまとめて管理し、本人確認とアクセス制御を行うための基盤です。</div>

## 会社の「社員名簿・鍵・管理台帳」
Active DirectoryにはユーザーやPCの情報が登録されます。利用者が会社のPCへサインインすると、ドメインコントローラーが資格情報を確認します。

<div class="scenario-flow"><span>ユーザーがサインイン</span><b>→</b><span>ドメインコントローラーが認証</span><b>→</b><span>所属グループと設定を確認</span><b>→</b><span>利用を許可</span></div>

## 主な構成要素
| 用語 | 初心者向けの意味 |
|---|---|
| ドメイン | 一つの管理範囲 |
| ドメインコントローラー | 認証とディレクトリ情報を提供するサーバー |
| ユーザー | 社員などのサインイン主体 |
| コンピューター | ドメインへ参加しているPCやサーバー |
| グループ | 権限をまとめて割り当てる単位 |
| OU | 管理対象を整理し、GPOなどを適用するための入れ物 |

## DNSとの関係
ドメイン参加、サインイン、GPO適用ではDNSが重要です。Active Directoryの障害に見えても、実際にはDNS設定が原因ということがあります。

::: tip 新人が最初に覚えること
ユーザーへ直接バラバラに権限を付けるのではなく、原則としてグループを使って管理します。人が異動しても、グループの所属を変更することで管理しやすくなります。
:::
